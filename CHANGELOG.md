# История изменений

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [Unreleased]

## [0.5.0] — 2026-10-29

### Added

- Работа с Яндекс Диском через ограниченный токен папки приложения: автоматическое создание подпапок ботов, выбор файлов и превью без доступа к личным файлам аккаунта.
- Команда подключения Диска, которая определяет папку через `app:/` и проверяет запрет доступа к корню Диска.

### Fixed

- Создание папки бота больше не требует доступа к родительским каталогам вне папки приложения.

## [0.4.3] — 2026-10-29

### Fixed

- Неудачные попытки входа с другого IP больше не блокируют владельца аккаунта.
- Смена неверного Content API токена больше не обходит ограничение запросов; Header и Bearer используют общий счётчик.
- Caddy принимает исходный IP только от доверенного контейнера Funnel и больше не объединяет посетителей в один лимит.

### Added

- Выкатка BotCRM с проверкой второй копии приложения, плавным переключением маршрутов и восстановлением предыдущей версии при ошибке.

- Публичная документация и материалы сообщества.

## [0.4.2] — 2026-10-28

### Fixed

- Отсутствующая папка одного контентного бота больше не блокирует загрузку и работу остальных ботов.

## [0.4.1] — 2026-10-28

### Fixed

- Существующие папки Яндекс Диска сначала проверяются чтением и не требуют права записи для повторного подключения.
- Для отсутствующей папки возвращается отдельная ошибка, если OAuth-токен не имеет права создавать каталоги.

## [0.4.0] — 2026-10-28

### Added

- Единый раздел автоответов для контентных ботов с текстом, медиа, кнопками и fallback.
- Изолированные профили и персональные токены BotCRM Content API.
- Автоматическое создание папок ботов внутри `/bot_crm` на Яндекс Диске.

### Changed

- Directus используется как внутреннее хранилище и больше не выдаёт административный доступ процессам ботов.

## [0.1.0] — 2026-08-23

### Added

- Единый realtime inbox и управление `BOT / HUMAN / PAUSED`.
- Контакты, типизированные переменные, сегменты, воронки и сделки.
- Рассылки с медиа, кнопками, расписанием и ограничениями каналов.
- CRM-автоматизации, аудит, RBAC, TOTP-MFA и rate limiting.
- Telegram, VK, WhatsApp Cloud, Avito и Generic REST connectors.
- TypeScript и Python SDK, OpenAPI и тестовый Telegram-бот.
- Production Docker Compose, Caddy HTTPS, backup/restore и monitoring.

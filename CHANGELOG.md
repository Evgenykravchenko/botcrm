# История изменений

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [Unreleased]

## [0.8.1] — 2026-10-31

### Fixed

- Помощник сохраняет структурированный черновик автоответа между сообщениями: добавление кнопки больше не теряет фразу, текст и файлы. Повторные уточнения известной ссылки заменены готовой правкой.
- Непустой черновик принимается даже без отдельного комментария модели. Ошибка относится к конкретному сообщению, а последний удачный вариант остаётся доступен для редактирования.
- У завершённых, но некорректных ответов учитывается известный фактический расход вместо полного резерва; неизвестные расходы после тайм-аута по-прежнему резервируются консервативно.

### Changed

- Справка по девяти разделам BotCRM и отказ от посторонних тем работают локально. В базу знаний включены роли, медиа, кнопки, fallback, интеграции и фактические расчёты аналитики.
- Типовые правки кнопок выполняются без платного запроса. Для генерации передаются только инструкция выбранного действия, короткая история, текущий черновик и нужные материалы.

## [0.8.0] — 2026-10-31

### Added

- AI-помощник в боковой панели: справка по BotCRM, подготовка автоответов с медиа и кнопками, сводки диалогов, черновики сообщений и задач.
- Проверка AI-черновиков в существующем редакторе. Помощник не публикует контент, не отправляет сообщения и не управляет сервером.
- Настройки подключения для рабочего пространства: OpenAI с экономной GPT-6 Luna и адаптер совместимых API, шифрование ключа, месячный бюджет и дневные лимиты пользователей.
- Атомарное резервирование расходов, идемпотентность запросов, ограничение контекста и ответа. Автоматические повторы, фоновая генерация и переключение на дорогие модели отключены.
- Изоляция по рабочему пространству и роли. История выбранного диалога передаётся провайдеру только после явного включения контекста; результаты сохраняются зашифрованными, без исходных промптов.

### Changed

- Дополнительный провайдер и транспорт настраиваются владельцем self-hosted сервера через окружение, без адресов конкретной установки в коде.

## [0.7.2] — 2026-10-29

### Fixed

- Синхронизация существующих профилей контента больше не перезаписывает неизменившиеся строки и не вызывает ложные realtime-обновления всей CRM.
- Одновременные одинаковые запросы чтения объединяются; события фокуса и realtime не запускают повторные полные загрузки подряд.
- При `429` JSON-запросы, превью и realtime соблюдают `Retry-After`. Панель показывает паузу обновлений, сохраняет редактор и сама возобновляет чтение данных. Запросы изменения данных автоматически не повторяются.
- Временный лимит при проверке сессии не отправляет пользователя на экран входа.

### Added

- Регрессионные проверки неизменяемости профилей, отсутствия ложных уведомлений PostgreSQL, объединения чтений и восстановления после лимита запросов.
- Постоянный шаблон GitHub Releases по образцу BotCRM v0.4.3 и правила его применения.

## [0.7.1] — 2026-10-29

### Fixed

- В диалогах подпись сообщения показывается под вложениями, включая обложки фото и видео.

## [0.7.0] — 2026-10-29

### Added

- Живой прогресс подготовки медиа: переданные байты, скорость и адаптивная оценка времени передачи. Очередь и завершающая обработка показываются без искусственного таймера.
- Обложки и встроенное воспроизведение видео в медиатеке, автоответах и диалогах с учётом ориентации кадра.

### Fixed

- Для превью вложений в диалогах используется технический идентификатор бота, а не отображаемое название.
- Обложки больше не обрезаются до квадрата, а изменение высоты медиа сохраняет положение в конце переписки, если оператор не читает старые сообщения.

## [0.6.0] — 2026-10-29

### Added

- Файлы сначала готовятся в медиатеке и становятся доступны для прикрепления к автоответу только после готовности. В редакторе показаны статусы и повтор подготовки при ошибке.
- Обновление статусов в открытом редакторе через существующее realtime-соединение с сохранением введённого текста и кнопок.

### Fixed

- API отклоняет прикрепление неготовых файлов до изменения автоответа, включая материалы без готового вложения и просроченные доставки Instagram.
- Замена исходного файла сбрасывает готовность и старые идентификаторы вложений.

## [0.5.0] — 2026-10-29

### Added

- Работа с Яндекс Диском через ограниченный токен папки приложения: автоматическое создание подпапок ботов, выбор файлов и превью без доступа к личным файлам аккаунта.
- Команда подключения Диска, которая определяет папку через `app:/` и проверяет запрет доступа к корню Диска.

### Fixed

- Создание папки бота больше не требует доступа к родительским каталогам вне папки приложения.

## [0.4.3] — 2026-10-29

### Fixed

- Неудачные попытки входа с другого IP больше не блокируют владельца аккаунта.
- Смена неверного Content API токена больше не обходит ограничение запросов; Header и Bearer используют общий счётчик.
- Caddy принимает исходный IP только от доверенного контейнера Funnel и больше не объединяет посетителей в один лимит.

### Added

- Выкатка BotCRM с проверкой второй копии приложения, плавным переключением маршрутов и восстановлением предыдущей версии при ошибке.

- Публичная документация и материалы сообщества.

## [0.4.2] — 2026-10-28

### Fixed

- Отсутствующая папка одного контентного бота больше не блокирует загрузку и работу остальных ботов.

## [0.4.1] — 2026-10-28

### Fixed

- Существующие папки Яндекс Диска сначала проверяются чтением и не требуют права записи для повторного подключения.
- Для отсутствующей папки возвращается отдельная ошибка, если OAuth-токен не имеет права создавать каталоги.

## [0.4.0] — 2026-10-28

### Added

- Единый раздел автоответов для контентных ботов с текстом, медиа, кнопками и fallback.
- Изолированные профили и персональные токены BotCRM Content API.
- Автоматическое создание папок ботов внутри `/bot_crm` на Яндекс Диске.

### Changed

- Directus используется как внутреннее хранилище и больше не выдаёт административный доступ процессам ботов.

## [0.1.0] — 2026-08-23

### Added

- Единый realtime inbox и управление `BOT / HUMAN / PAUSED`.
- Контакты, типизированные переменные, сегменты, воронки и сделки.
- Рассылки с медиа, кнопками, расписанием и ограничениями каналов.
- CRM-автоматизации, аудит, RBAC, TOTP-MFA и rate limiting.
- Telegram, VK, WhatsApp Cloud, Avito и Generic REST connectors.
- TypeScript и Python SDK, OpenAPI и тестовый Telegram-бот.
- Production Docker Compose, Caddy HTTPS, backup/restore и monitoring.

# AI-помощник BotCRM

Помощник доступен по кнопке в правом нижнем углу. Он объясняет настройки, готовит автоответы, помогает с выбранной перепиской и предлагает задачи. Сохранение контента, создание задачи и отправка сообщения остаются явными действиями пользователя.

## Первое подключение

1. Войти как владелец или администратор рабочего пространства.
2. Открыть **Помощник → Настройки**.
3. Выбрать провайдера, вставить новый API-ключ в закрытое поле, установить месячный бюджет и дневной лимит запросов на человека.
4. Включить помощника и сохранить. Сохранение настроек не вызывает модель и не расходует токены.
5. Отправить короткий запрос, например «Как создать автоответ с фото?».

По умолчанию используется OpenAI GPT-6 Luna: $0,10 за миллион входных и $0,50 за миллион выходных токенов по тарифам на 31 октября 2026 года. Расчёт бюджета не учитывает скидки, кеширование или бесплатные кредиты провайдера. Изменения тарифов требуют обновления конфигурации адаптера; фактические списания сверяются в кабинете провайдера.

Начальные ограничения: месячный бюджет $5, 100 запросов в день на человека, один активный запрос пользователя и два на рабочее пространство. Администратор может изменить бюджет от $0,10 до $100 и дневной лимит от 1 до 1000. Периоды бюджета считаются по UTC.

**OpenAI не получает доступ к серверу.** Приложение отправляет ограниченный текстовый контекст и получает структурированный результат. API-ключ зашифрован существующим ключом шифрования CRM и не возвращается браузеру. Модель не видит env-файлы, ключи коннекторов, Vault, базы целиком или данные другого рабочего пространства.

## Автоответы

Выберите бота в панели помощника и опишите ответ обычными словами. Например: «На слово “прайс” подготовь короткий ответ и прикрепи готовое фото прайса из медиатеки».

Помощник может выбрать только существующие готовые материалы выбранного бота, максимум 10 файлов. Если подходящего материала нет или он ещё готовится, нужно уточнить запрос или дождаться готовности. Файлы в папке Диска, которые ещё не добавлены в медиатеку, сначала добавляются обычным способом.

Карточка **Проверить в редакторе** открывает штатный редактор с текстом, файлами и кнопками. Новый ответ имеет статус «Черновик». Можно отредактировать содержимое, проверить предпросмотр, выбрать публикацию и сохранить. Сервер повторно проверяет права и готовность файлов при сохранении.

## Переписка и задачи

В разделе «Диалоги» выберите обращение и включите **Передать AI последние сообщения**. Только после этого имя контакта и до 12 последних текстовых сообщений попадут к выбранному провайдеру. Номера телефонов, email, произвольные поля и содержимое вложений не загружаются автоматически. Сам текст сообщений может содержать персональные данные: включайте передачу только для допустимой у вас обработки данных.

Можно попросить сводку, вариант ответа или задачу. **Добавить в черновик сообщения** дополняет поле ввода исходного диалога, не отправляя сообщение. Отправка и перехват диалога работают по обычным правилам BotCRM. Карточка задачи показывает название и дату; задача создаётся по отдельному нажатию пользователя.

При смене бота или выбранного диалога история чата помощника очищается. Старый ответ не вставляется в другой диалог. История чата хранится в памяти открытой панели и пропадает после перезагрузки страницы; до шести последних коротких реплик передаются в следующем запросе. Исходные запросы не пишутся в журнал расходов. Зашифрованные результаты для защиты от повторных запросов хранятся до 90 дней и очищаются при последующих запросах этого рабочего пространства.

## Контроль расходов

- Один запрос к модели на действие, максимум 1400 выходных токенов. Ограничены сообщение, история и контекст; большие запросы отклоняются.
- До обращения к провайдеру PostgreSQL атомарно резервирует верхнюю оценку расхода. Две параллельные заявки не могут одновременно потратить один остаток бюджета.
- После успешного ответа резерв заменяется оценкой по фактическому расходу токенов. Запись кеша OpenAI учитывается с надбавкой; скидки за попадания в кеш не уменьшают оценку бюджета. При ошибке или тайм-ауте резерв сохраняется: отсутствие ответа не доказывает, что провайдер не списал средства.
- Повторная отправка того же идентификатора не создаёт второй платный вызов. Неудачный запрос автоматически не повторяется.
- Исчерпание AI-бюджета не включает общую паузу API и не влияет на диалоги, ботов или автоответы.
- Приложение ограничивает собственные запросы. Оно не контролирует использование того же ключа в сторонних приложениях, налоги и новые тарифы провайдера.

## Другие провайдеры

OpenAI использует Responses API. Дополнительный адаптер поддерживает серверы с совместимым Chat Completions API и структурированным JSON-ответом. Это не гарантирует совместимость со всеми LLM: сервер должен поддерживать указанную модель, формат JSON Schema и возвращать расход токенов. Неполный или некорректный ответ отклоняется и не меняет CRM.

Параметры задаются владельцем сервера, а не из чата:

```dotenv
ASSISTANT_COMPATIBLE_BASE_URL=https://llm.example.com/v1
ASSISTANT_COMPATIBLE_MODEL=your-model
ASSISTANT_COMPATIBLE_INPUT_PRICE=1
ASSISTANT_COMPATIBLE_OUTPUT_PRICE=5
```

Цены — доллары за миллион токенов. Для доверенного локального HTTP endpoint дополнительно требуется `ASSISTANT_ALLOW_HTTP=true`. API-ключ выбранного провайдера вводится в настройках рабочего пространства. При смене провайдера старый ключ не переносится автоматически.

Если инфраструктуре нужен исходящий прокси, необязательная переменная `ASSISTANT_OPENAI_PROXY_URL` задаёт его для OpenAI; при её отсутствии используется `HTTPS_PROXY`. `ASSISTANT_REQUIRE_PROXY=true` запрещает прямой запрос при отсутствии прокси. При ошибке прокси обход напрямую не выполняется. В обычной установке эти параметры не требуются.

Новые native-провайдеры добавляются через интерфейс `AssistantProvider`, без переписывания чата, ролей, бюджетов и редактора.

## Обновление

Используйте обычную [blue/green-выкатку](SAFE_DEPLOY.md). Миграция `014_ai_assistant.sql` только добавляет таблицы и совместима с предыдущим слотом приложения. Без настройки AI-помощник отключён; ключи ботов, Directus и Vault менять не требуется.

После выкатки проверьте справку, черновик автоответа, передачу выбранного диалога, вставку текста без отправки и ограничения бюджета. Реальные тесты с провайдером выполняйте отдельно с небольшим бюджетом; CI использует синтетические ключи и локальные ответы.

# Автоответы по ключевым словам

Раздел **«Автоответы»** позволяет редактору менять выдачу контента без доступа к коду и без нового релиза бота. BotCRM показывает понятный интерфейс, а отдельная Content Platform (Directus) остаётся источником истины для VK-, Instagram- и других ботов, работающих по ключевым словам.

## Что можно настроить

- фразу и режим совпадения: точно, содержит фразу, любое или все слова;
- приоритет и включение правила;
- черновик или опубликованный ответ;
- несколько текстовых и медиаблоков в нужном порядке;
- фото, видео, аудио и документы с Яндекс Диска;
- кнопки-команды и кнопки-ссылки;
- короткий fallback или полноценный готовый ответ, если правило не найдено.

BotCRM не отвечает пользователю сам. Сообщение по-прежнему обрабатывает конкретный бот, который читает опубликованный контент из общей платформы. Поэтому не возникает двух параллельных обработчиков одного сообщения.

## Граница между системами

| Система | Отвечает за |
|---|---|
| BotCRM | удобный интерфейс, роли пользователей и изоляцию рабочих пространств |
| Content Platform / Directus | правила, ответы, блоки, кнопки, fallback и техническое состояние медиа |
| Worker конкретного бота | подготовку файла с Яндекс Диска для своей платформы |
| VK / Telegram / Instagram бот | поиск правила и отправку готового ответа пользователю |

Токен Directus хранится только в окружении API BotCRM. Браузер пользователя его не получает.

## Подключение Content Platform

В окружение API добавьте:

```dotenv
CONTENT_PLATFORM_URL=https://content.example.ts.net
CONTENT_PLATFORM_TOKEN=directus-server-token
CONTENT_PLATFORM_YANDEX_TOKEN=yandex-disk-oauth-token
CONTENT_PLATFORM_BINDINGS=[{"workspaceId":"00000000-0000-4000-8000-000000000001","botSlug":"vk_test_bot","contentBotKey":"vk-content-bot","label":"VK Content Bot","channel":"vk","yandexRoot":"/VK Content Bot"}]
```

`CONTENT_PLATFORM_BINDINGS` — обязательный белый список. Одна запись связывает:

- `workspaceId` — UUID рабочего пространства BotCRM из `GET /api/v1/auth/me`;
- `botSlug` — технический slug бота в BotCRM;
- `contentBotKey` — поле `key` бота в коллекции `content_bots` Directus;
- `label` — понятное название в интерфейсе;
- `channel` — `vk`, `telegram`, `instagram` или `other`.
- `yandexRoot` — корневая папка медиатеки этого бота на Яндекс Диске.

`CONTENT_PLATFORM_YANDEX_TOKEN` остаётся только на API-сервере. Интерфейс получает список файлов и временные превью, но никогда не получает OAuth-токен.

Один workspace не может открыть контент другого, даже если пользователь подставит чужой `botSlug` в запрос вручную.

## Работа редактора

1. Откройте **Автоответы** и выберите бота.
2. Нажмите **Новый автоответ**, введите ключевую фразу и текст ответа.
3. Чтобы добавить фото или видео, нажмите **Выбрать с Яндекс Диска** и выберите файл карточкой. Путь вводить не нужно.
4. При желании добавьте кнопки. Технические параметры спрятаны в **Дополнительных настройках**.
5. Проверьте ответ в превью и нажмите **Сохранить**.
6. Во вкладке **Если ничего не найдено** настройте общий запасной ответ.

Операторы могут просматривать настройки. Создавать и изменять контент могут владелец, администратор и супервайзер.

## Отказоустойчивость

- недоступность Content Platform затрагивает только раздел «Автоответы», остальные разделы CRM продолжают работать;
- API ограничивает время внешнего запроса восемью секундами;
- секреты и исходные ошибки Directus не возвращаются в браузер;
- создание ответа выполняется с компенсирующей очисткой, если вложенный блок или кнопка не сохранились;
- удаление правила не удаляет общий ответ, если его использует другое правило.

## Работа с медиатекой

- Файлы выбираются с Яндекс Диска и появляются в медиатеке. Оригинал продолжает храниться на Диске.
- Повторный выбор того же пути на Яндекс Диске использует уже существующую карточку и не создаёт дубликат.
- Корзина убирает карточку только из медиатеки BotCRM — файл на Яндекс Диске не удаляется.
- Материал, который используется в автоответе, защищён от удаления. Сначала открепите его, сохраните автоответ, затем уберите из медиатеки.
- В медиатеке может быть сколько угодно материалов; найти нужный помогает поиск. К одному ответу можно прикрепить не более 10 файлов.
